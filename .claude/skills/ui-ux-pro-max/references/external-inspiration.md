# External Inspiration Sources

Community-curated design references to consult alongside this skill's local database when exploring UI styles, themes, or full page templates.

- **21st.dev Community Themes** — https://21st.dev/community/themes
  Community-submitted component themes (color systems, tokens, component styling variants).
- **21st.dev Community Templates** — https://21st.dev/community/templates
  Community-submitted full page/product templates (landing pages, dashboards, etc.).

Use these as visual inspiration and pattern reference; validate any adopted style against this skill's accessibility, performance, and UX guideline checks (see `quick-reference.md` and `pro-rules.md`) before applying it to a project.
