# EAC

## Inspirations design

Sources externes à consulter pour l'inspiration UI/UX (styles, thèmes, templates) lors du travail de design sur ce repo :

- https://21st.dev/community/themes — thèmes de composants communautaires
- https://21st.dev/community/templates — templates de pages/produits communautaires

⚠️ Ces deux domaines sont bloqués par la politique réseau des environnements Claude Code on the web utilisés sur ce repo (403 en sortie, comme pour ecole-eac.com). Ne pas prétendre s'en être inspiré tant que l'accès n'est pas vérifié en début de tâche — si le fetch échoue, le dire explicitement à l'utilisateur plutôt que d'ignorer la consigne silencieusement.

Toujours utiliser le skill `ui-ux-pro-max` (`.claude/skills/ui-ux-pro-max/`) pour tout travail de design UI/UX sur ce repo : lancer `search.py --design-system` avant de proposer une direction visuelle, et vérifier les guidelines UX (accessibilité, touch targets, contraste) avant de livrer.
